# 라이브 방송 — 현장 1페이지 (인쇄용)

> 노트북 옆에 붙여 두세요. 자세한 내용은 `docs/live-broadcast.md`.

## 시작 순서

1. **OBS** 송출 켜기 → 유튜브 스튜디오에서 화면 들어오는지 확인
2. **탈리 화면**을 현장 노트북에 전체화면(F11)
3. **스위처 콘솔**을 감독 노트북에 + 옆에 **OBS 멀티뷰**
4. 어드민 → 라이브 방송관리 → **방송 시작**

## 스위처 단축키

```
 1  2  3  4     해당 앵글로 전환
 Space          직전 앵글로 되돌리기
 ?              도움말
```

**클릭 = 즉시 송출. 확인 창 없음. 되돌리기 없음.**
입력칸에 커서가 있으면 단축키는 안 먹습니다.

## 화면에서 봐야 할 것

| 표시 | 뜻 |
|---|---|
| 붉은 테두리 + ON AIR | 지금 유튜브로 나가는 앵글 |
| 카드에 깔린 화면 | 그 앵글의 프리뷰 — **지연이 있는 참고 화면**. 정밀 확인은 OBS 멀티뷰 |
| 카드가 회색 (`프리뷰 주소 없음`) | 그 앵글에 프리뷰 주소를 안 넣은 것. 전환에는 지장 없음 |
| 버튼의 시간 | 이 앵글을 유지한 시간 (90초 넘으면 주황색) |
| `브리지: 연결됨 / 끊김` | 모드 B 자동 전환 가능 여부 |
| 상단 붉은 띠 | 카메라 끊김 또는 브리지 오류 — 즉시 조치 |

## 문제가 생기면

| 상황 | 첫 번째 조치 |
|---|---|
| 브리지 끊김 | 스위처 상단에서 **모드 A**로 전환 → 오퍼레이터가 탈리 보고 수동 전환 |
| 카메라 1대 사망 | 그 카메라 **끊김** 클릭 → 선택 차단. 나가고 있었으면 즉시 다른 앵글 |
| 유튜브 재생 불가 | 어드민 → 영상 소스 **백업(HLS)** → 저장 (채팅은 자동 숨김) |
| 시청자 화면 안 바뀜 | 1분 기다린 뒤에도 그대로면 새로고침 안내 |
| 채팅이 빈칸 | 환경변수 문제 — 개발자에게 연락 |

**브리지 복구보다 방송 유지가 먼저입니다. 모드 A로 내리면 방송은 계속됩니다.**

## 끝낼 때

1. 어드민 → **방송 종료**
2. 유튜브 다시보기 준비되면 → **다시보기 공개**
3. 스위처 → **CSV** 내려받아 보관 (VOD 챕터·클립 추출용)
