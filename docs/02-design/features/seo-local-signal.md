# 로컬 시그널(주소) 전략 — Local SEO

"이 페이지는 **어느 지역의 어느 장소**에서 열리는 행사인가"를 검색엔진이 확신하게 만드는 규칙.
구현 단일 소스는 [`packages/shared/src/address.ts`](../../../packages/shared/src/address.ts).

## 왜 졌나 (진단)

경쟁 페이지(TryBooking)는 온페이지가 부실한데도 로컬 시그널 9/10 — **본문에 실제 주소가 텍스트로 있기 때문**이다
(`64 Dawson St, Brunswick VIC 3056`). WOLF 는 3/10 이었고 원인은 셋이었다.

| 원인 | 상태 |
|---|---|
| 입력 UI 에 도시·시/도·우편번호 칸이 아예 없었다 | 오거나이저가 채울 방법이 없어 전 행사 공란 |
| 주소가 본문에 노출되지 않았다 | 히어로/사이드바에 한 줄 요약만 — 크롤러가 읽을 주소 블록 없음 |
| 좌표·지도 링크가 없었다 | `Place.geo`·`hasMap` 부재 |

## 4계층 전략

로컬 시그널은 한 곳만 고쳐서 오르지 않는다. **입력 → 렌더 → 구조화 → 문맥** 네 곳이 같은 사실을 말해야 한다.

### 1계층 — 입력 (데이터가 없으면 나머지는 전부 빈손)
행사 장소 단계에 도시 / 시·도 / 우편번호 / 지도 링크를 추가하고, 도시·시도는 i18n 으로 받는다
(한글 제목엔 `방콕`, 영문 제목엔 `Bangkok` 이 들어가야 하므로).
좌표는 손입력을 기대하지 않는다 — **구글맵 URL 을 붙여넣으면 `@lat,lng` 등에서 자동 추출**한다(`parseGeoFromMapUrl`).

### 2계층 — 렌더 (크롤러가 텍스트로 읽는 근거)
장소 섹션 맨 위에 NAP 블록을 고정 노출한다. 오거나이저가 '행사 장소' 섹션을 안 썼어도
주소 데이터가 있으면 섹션 자체가 생긴다.

- 베뉴명 (강조)
- `<address>` 시맨틱 태그 안에 우편주소 한 줄
- 지도에서 보기 링크 (좌표 있으면 좌표, 없으면 "베뉴명+주소" 검색 URL)

표기 순서는 로케일을 따른다 — 한국어·일본어·중국어는 큰 단위부터(국가·시도·도시·상세),
영어는 작은 단위부터(도로명·도시·주·우편번호·국가).

### 3계층 — 구조화 (schema.org)
`Event.location` 을 완전한 `Place` 로 만든다.

```jsonc
"location": {
  "@type": "Place",
  "name": "Victory Hotel",              // 베뉴명. 없으면 도시 → 국가로 대체
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "149 Thuy Van",
    "addressLocality": "Vung Tau",
    "addressRegion": "Ba Ria–Vung Tau",
    "postalCode": "790000",
    "addressCountry": "VN"              // 표시명 아닌 ISO 3166-1 alpha-2 (구글 권장)
  },
  "geo": { "@type": "GeoCoordinates", "latitude": 10.34, "longitude": 107.08 },
  "hasMap": "https://www.google.com/maps/search/?api=1&query=10.34,107.08"
}
```

### 4계층 — 문맥 (제목·설명·내부 링크)
- 타이틀 태그가 도시/국가를 담는다 → [seo-title.md](./seo-title.md)
- 도시가 채워지면 제목이 국가 대신 **도시**를 쓰므로 지역 검색 매칭이 올라간다

## 데이터 품질 규칙

| 규칙 | 이유 |
|---|---|
| 베뉴 칸에 도시명을 넣지 않는다 (`venue: "Melbourne"` ✗) | `Place.name` 이 도시가 되어 장소 식별이 흐려진다. 호텔·스튜디오·컨벤션센터 이름을 쓴다 |
| 주소 칸에 국가까지 통째로 넣어도 된다 | 중복 조각은 출력 시 자동으로 걸러진다(`formatPostalAddress`) |
| 숫자가 섞인 값은 도시로 쓰지 않는다 (`B1`, `64 Dawson St`) | 층수·도로명이 도시 자리에 들어가면 지역 신호가 오염된다 |
| 좌표 (0,0) 은 버린다 | 미입력을 좌표로 오인하면 엉뚱한 위치(기니만)로 색인된다 |

## 다음 단계 (이 문서 범위 밖)

- **국가·도시별 행사 허브 페이지** (`/{locale}/events/{country}`): "태국 라틴 페스티벌" 류 검색을 받는
  랜딩을 만들고 상세로 내부 링크를 건다. 로컬 시그널과 URL 구조를 동시에 끌어올리는 다음 카드.
- **오거나이저 프로필 NAP 일관성**: 같은 주최자의 여러 행사가 같은 주소 표기를 쓰게 한다.
