Small pill badge for statuses, categories, and tags — e.g. "얼리버드", "매진 임박", festival genres. The only place Wolf uses pill geometry.

```jsx
<Badge variant="orange">얼리버드</Badge>
<Badge variant="cream">3-DAY PASS</Badge>
<Badge variant="dark">SOLD OUT</Badge>
<Badge variant="outline">EDM</Badge>
```

Variants: `orange` · `cream` · `dark` · `outline`.
