# 123Band OBS 브리지

123Band 스위처에서 감독이 고른 앵글대로 **현장 OBS의 씬을 자동으로 바꿔 주는** 작은 프로그램입니다.
현장 노트북(OBS가 돌아가는 그 컴퓨터)에서 실행합니다.

```
감독이 123Band 스위처에서 2번 클릭
   → 이 프로그램이 1초 안에 알아챔
   → OBS 씬이 '플로어'로 바뀜
   → 유튜브로 나가는 화면이 바뀜
```

**이 프로그램이 없어도 방송은 됩니다.** 그때는 모드 A로 운영합니다 — 탈리 화면에 뜨는 번호를 보고
오퍼레이터가 OBS에서 직접 씬을 누르면 됩니다. 브리지가 중간에 죽어도 방송은 끊기지 않습니다.

---

## 1. 준비 (행사 전날까지)

### OBS 쪽

1. OBS를 켭니다.
2. 상단 메뉴 **도구 → obs-websocket 설정**을 엽니다.
3. **웹소켓 서버 활성화**를 체크합니다.
4. 포트(기본 `4455`)와 **서버 비밀번호**를 확인해 적어 둡니다. (비밀번호 표시 버튼을 누르면 보입니다)
5. 씬 4개를 만들고 이름을 정합니다. 예: `Main`, `Floor`, `Judges`, `Wide`
   - 이름은 나중에 123Band에 그대로 입력하므로 **짧고 헷갈리지 않게** 지으세요.

### 123Band 쪽

1. 어드민 → **라이브 방송관리** → 해당 방송을 엽니다.
2. 카메라 1~4번에 이름과 **OBS 씬 이름**을 넣습니다.
   - 대소문자·공백까지 정확히 같아야 합니다. `Main`과 `main`은 다른 씬입니다.
   - 브리지를 한 번 실행한 뒤에는 OBS의 실제 씬 목록이 드롭다운으로 나오므로 골라 넣으면 됩니다.
3. **탈리 주소 복사**를 누릅니다. 주소 끝의 `t=` 뒤에 붙은 긴 문자열이 **현장 토큰**입니다.

---

## 2. 설치 (한 번만)

노트북에 [Node.js 20 이상](https://nodejs.org)이 설치돼 있어야 합니다.

```bash
cd tools/obs-bridge
npm install
```

> 이 폴더는 123Band 웹앱과 완전히 분리돼 있습니다. 여기서 설치한 것은 웹사이트에 아무 영향을 주지 않습니다.

설정 파일을 만듭니다.

```bash
cp .env.example .env
```

`.env`를 열어 네 가지를 채웁니다.

| 항목 | 어디서 얻나 |
|---|---|
| `SUPABASE_URL`, `SUPABASE_ANON_KEY` | 개발자에게 요청 (공개 키라 노트북에 둬도 됩니다) |
| `BAND_FIELD_TOKEN` | 어드민에서 복사한 탈리 주소의 `t=` 뒤 문자열 |
| `OBS_PASSWORD` | OBS의 obs-websocket 설정에 있는 서버 비밀번호 |

---

## 3. 실행 (행사 당일)

OBS를 먼저 켠 다음:

```bash
cd tools/obs-bridge
npm start
```

이런 화면이 나오면 정상입니다.

```
  123Band OBS 브리지
  OBS: ws://127.0.0.1:4455
  확인 주기: 1000ms
  종료하려면 Ctrl+C — 종료해도 방송은 계속됩니다(모드 A 로 진행하세요).

[19:02:11] ✓ OBS 에 연결했습니다 (ws://127.0.0.1:4455)
[19:02:11] ✓ 씬 4개를 123Band 에 등록했습니다: Main, Floor, Judges, Wide
[19:14:35] 지시: 2번 플로어 → 씬 "Floor"
[19:14:35] ✓ 씬을 "Floor" 로 바꿨습니다
```

**이 창을 닫지 말고 켜 두세요.** 현장에서 무슨 일이 일어나는지 이 창이 다 말해 줍니다.

마지막으로 123Band 스위처 상단에서 모드를 **모드 B — 브리지 자동 전환**으로 바꾸면
감독의 클릭이 OBS까지 이어집니다. (모드 A로 두면 브리지는 지시를 로그로만 남기고 씬을 바꾸지 않습니다)

## 4. 이런 메시지가 나오면

| 메시지 | 뜻과 조치 |
|---|---|
| `OBS 연결 실패 … 다시 시도합니다` | OBS가 꺼져 있거나 웹소켓 서버가 꺼져 있습니다. OBS를 켜고 도구 → obs-websocket 설정을 확인하세요. 켜지면 알아서 다시 붙습니다 |
| `123Band 가 토큰을 받아들이지 않았습니다` | `.env`의 `BAND_FIELD_TOKEN`이 틀렸습니다. 어드민에서 탈리 주소를 다시 복사하세요 |
| `카메라 2(플로어)의 씬 "Floor" 이 OBS 에 없습니다` | 씬 이름이 어긋났습니다. OBS의 씬 이름과 123Band의 입력이 정확히 같은지 보세요(대소문자 포함) |
| `씬 전환 실패: …` | OBS가 전환을 거부했습니다. 스위처 화면에도 빨갛게 뜹니다. 오퍼레이터가 수동으로 바꾸고, 모드 A로 내려서 계속 진행하세요 |
| `OBS 연결이 끊겼습니다` | 자동으로 재접속합니다(최대 30초 간격). 그동안 스위처에는 '끊김'으로 표시됩니다 |

**브리지가 말썽이면 주저 말고 모드 A로 내리세요.** 스위처 상단 드롭다운에서 모드 A를 고르면
그 즉시 탈리 화면 지시 방식으로 돌아갑니다. 방송은 멈추지 않습니다.

---

## 5. 카메라 신호 상태 (참고)

브리지는 10초마다 각 씬 안의 미디어 소스(SRT/미디어 소스) 상태를 살펴, 재생 중이면 `정상`,
오류·종료 상태면 `끊김`으로 123Band에 보고합니다. 미디어 소스가 없는 씬은 판단하지 않습니다
(감독이 스위처에서 직접 표시한 상태를 덮어쓰지 않기 위해서입니다).

즉 이 값은 **참고용**입니다. 최종 판단은 OBS 멀티뷰를 보는 사람이 합니다.

---

## 6. 자주 묻는 것

**Q. 브리지를 여러 대에서 돌려도 되나요?**
한 방송에는 한 대만 돌리세요. 두 대가 같은 토큰으로 붙으면 씬 전환이 서로 겹칩니다.

**Q. 방송이 바뀌면요?**
`.env`의 `BAND_FIELD_TOKEN`을 새 방송의 토큰으로 바꾸고 다시 실행하세요.

**Q. 스위처에서 앵글을 눌렀는데 OBS가 안 바뀝니다.**
① 이 창에 `지시:` 줄이 뜨는지 → 안 뜨면 토큰/인터넷 문제
② 뜨는데 `모드 A` 라고 나오면 → 스위처에서 모드 B로 바꾸세요
③ `씬 전환 실패`가 뜨면 → 씬 이름이 다릅니다
